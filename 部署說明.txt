黃鼎彥的財富密碼 — 部署說明（王子做一次，客戶不用做）

【先試玩（不用永豐帳號）】
雲端平台環境變數加上 DEMO=1 → 假行情、假下單，可先給客戶看畫面。

【正式上線】
1. 把整個資料夾上傳到 GitHub
2. 到支援 Docker 的雲端平台（如 Zeabur、Render、Railway）新建專案，選這個 GitHub 專案，會自動用 Dockerfile 部署
3. 部署完會得到一個網址 → 傳給客戶

【觀察模式（客戶免申請 API）】
在雲端平台環境變數加入你自己（營運者）的永豐行情金鑰，權限只勾「行情」：
  SJ_API_KEY=...   SJ_SEC_KEY=...
客戶打開網址按「先觀察（免申請）」就能看即時訊號，不能下單。
※ 用你的帳號行情提供給他人觀看，請先向永豐確認是否允許。

【交易模式】客戶要做的：
1. 永豐金證券網站：簽署 API 文件 → 申請 API Key（Secret Key 只顯示一次）
2. 要下單還需：憑證檔(.pfx)、憑證密碼、身分證字號；永豐規定首次使用要先完成 API 模擬測試
3. 手機打開網址 → 輸入自己的金鑰登入 → 瀏覽器選「加入主畫面」，之後像 App 一樣點開
4. 同一組金鑰登入的手機、電腦，畫面與下單全部即時同步

【注意】
- 主機重開後需重新登入一次
- 下單為市價單，按下後會再跳一次確認
- 參數在 engine.py：Engine(N=3, M=5, GAP=5)

【背景推播通知（新版加入）】
客戶按「開啟提示通知」後，App 關掉、手機鎖屏也收得到訊號通知，按下去會先收到一則「測試通知」。
- iPhone 需 iOS 16.4 以上，而且一定要先「加入主畫面」，從主畫面圖示打開再按
- 建議在雲端平台設定一個「持久化磁碟（Volume）」掛在 /data，並加環境變數 DATA_DIR=/data
  沒設定的話，主機重建後通知訂閱會消失，客戶要再按一次「開啟提示通知」
- （選填）VAPID_SUBJECT=mailto:你的Email

【本版修正】
